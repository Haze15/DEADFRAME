      05 — PARAMÈTRES

      Réglages

      À pied — clavier AZERTY

      ZQSD déplacement   Maj sprint   Espace saut   C accroupi   AE se pencher
      Clic G tir   Clic D visée   R recharger — maintenu : vérifier le chargeur   1–4 / molette : arme   V inspecter
      F lampe   G drone   Tab scores   Échap menu

      Drone FPV — CORBEAU-1

      G lancer / prendre / rendre le contrôle   T mode ANGLE / ACRO   X retourner le drone s'il est sur le dos   F rappel   Échap quitter le mode drone
      ANGLE (stabilisé) : ZS tangage   QD roulis   AE ou souris : lacet   Espace / Ctrl gaz (relâchés : vol stationnaire à plat)   Maj plein gaz
      ACRO (manuel, saltos) : souris ou ZQSD tangage / roulis   AE lacet   Espace / Ctrl montent ou baissent les gaz, qui restent en place   Maj plein gaz
      ↑↓ inclinaison de la caméra   molette ou +− zoom
