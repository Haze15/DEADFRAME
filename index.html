Commandes

À pied — clavier AZERTY

ZQSD se déplacer   Maj sprint   Espace saut   C s'accroupir   AE se pencher
Clic G tirer   Clic D viser   R recharger, maintenu : vérifier le chargeur   1–4 ou molette : arme   V inspecter
F lampe   G drone   Tab scores   Échap menu

Drone FPV

Mode ANGLE : ZS tangage   QD roulis   AE ou souris : lacet   EspaceC monter / descendre
Modes HORIZON et ACRO : souris tangage / roulis   ZS manette des gaz (elle reste en place)   QD lacet   C couper les gaz
T mode de vol   X armer / désarmer / retourner   ↑↓ inclinaison caméra   G rendre la main (vol stationnaire)   F rappel
